# 外匯情報雲端橋接

沿用 Python（程式語言）既有蒐集與固定規則分析，搭配 GitHub Actions（自動化排程）、Cloudflare Workers（雲端入口）、D1（持久化資料庫）及 Telegram（手機通知）。只讀公開來源，完全沒有下單或交易帳戶功能。

目前只有 ECB（歐洲中央銀行）每日參考價，沒有即時買賣價；策略未通過實盤資格。分數不是勝率。現階段不會產生合格交易訊號，也不會以模擬通知冒充研究訊號。所有交易通知標示「研究訊號，非已驗證交易策略」。

公開專案僅含程式及公開來源端點，不含資料庫、行情原始內容、金鑰、個人帳戶或交易紀錄。研究風險上限為通用固定情境，不代表連接真實帳戶。

執行：`python3 -m unittest discover -s tests -v`；部署後由 `python3 -m cloud.runner` 分析。程式不依賴前一次執行器檔案：每輪從 D1 校驗並還原 SQLite（嵌入式資料庫）快照，結束後提交新快照及獨立查詢紀錄。

安全設定使用伺服器端機密；手機入口使用至少32字元隨機密碼及安全工作階段，登入失敗限流，不提供本機管理功能。正式啟動前須確認免費方案、獨立資料庫、金鑰權限及實際雲端驗收。

排程為每小時第8、38分。GitHub 可能延遲或漏執行，公開專案60天無活動可能停用排程。另一個雲端監控在第18、48分檢查75分鐘未完整成功及連續失敗。超過免費保守限額會停止，不會升級付費。

保存期限：新聞30日、分析及執行90日、參考價180日、通知180日。沒有即時報價時，後續預測驗證明確記錄資料不足，不補造績效。Telegram 網路逾時可能已送達，將標記不明且不盲目重送；不能宣稱絕對只送一次且保證送達。
