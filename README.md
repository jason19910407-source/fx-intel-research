# 外匯情報雲端橋接

沿用 Python（程式語言）既有蒐集與固定規則分析，搭配 GitHub Actions（自動化排程）、Cloudflare Workers（雲端入口）、D1（持久化資料庫）及 Resend（電子郵件寄送服務）。只讀公開來源，完全沒有下單或交易帳戶功能。

目前只有 ECB（歐洲中央銀行）每日參考價，沒有即時買賣價；策略未通過實盤資格。分數不是勝率。現階段不會產生合格交易訊號，也不會以模擬通知冒充研究訊號。所有交易通知標示「研究訊號，非已驗證交易策略」。

公開專案僅含程式及公開來源端點，不含資料庫、行情原始內容、金鑰、個人帳戶或交易紀錄。研究風險上限為通用固定情境，不代表連接真實帳戶。

執行：`python3 -m unittest discover -s tests -v`；部署後由 `python3 -m cloud.runner` 分析。程式不依賴前一次執行器檔案：每輪從 D1 校驗並還原 SQLite（嵌入式資料庫）快照，結束後提交新快照及獨立查詢紀錄。

安全設定使用伺服器端機密；手機入口使用自行設定的至少12字元密碼，登入後維持30天；密碼更換會撤銷舊登入，登出會在伺服器端撤銷該裝置工作階段。新密碼不保存明文，登入失敗限流，不提供本機管理功能。正式啟動前須確認免費方案、獨立資料庫、金鑰權限及實際雲端驗收。

分析由Cloudflare Cron（雲端定時事件）在每小時第8、38分啟動GitHub Actions（雲端工作流程），附上持久化啟動收據。GitHub原生排程保留觀察；兩者共用D1半小時時槽，防止依序重複分析。原生GitHub排程可能延遲或漏執行，公開專案60天無活動可能停用排程。另一個雲端監控在第18、48分檢查75分鐘未完整成功及連續失敗。超過免費保守限額會停止，不會升級付費。

保存期限：新聞30日、分析及執行90日、參考價180日、通知180日。沒有即時報價時，後續預測驗證明確記錄資料不足，不補造績效。Resend使用24小時冪等識別碼，配合持久化寄送紀錄，最多三次有限重試；連線結果不明不會冒稱未寄出，也不保證一定送達。

外匯沿用既有Resend技術，使用獨立授權、寄送紀錄及限額；不呼叫房仲提醒端點、不轉移原房仲金鑰。設定金鑰前不會實際寄送測試信。

Cloudflare呼叫GitHub使用manual（不自動跟隨）轉址模式；轉址回應視為失敗，不把授權標頭轉送其他目的地。啟動介面接受請求不等於分析完成，必須交叉核對雲端定時收據、GitHub工作編號及D1成功分析。另有登入保護的唯讀連線預檢，不建立分析工作，也不能代替排程驗收。

第二版分階段升級：八組貨幣對共用明確行情契約，日線以紐約17:00結算，小時線以世界協調時間對齊。缺漏不補價、不將每日參考匯率當作即時報價；尚未找到完成時間、授權與穩定性驗證的免費最新行情來源，故可執行構想保持關閉。歷史行情及資料庫不隨公開程式發布。技術引擎固定採20/60期均線、14期相對強弱與平均真實波幅、12/26/9期平滑異同均線及前20期支撐壓力；需要完整閉合回看視窗。新聞方向沒有驗證依據時不補分。尚未通過交易策略驗證，持有週期比較回測尚未完成。

正式研究報告只在台灣時間00、08、12、16、20點所屬時槽建立，依雲端分析完成時間發布，明確紀錄延遲；不包含04點。研究報告保存30日並記錄資料限制；電子郵件未完成獨立授權與送達測試前不寄送。八組市場研究移至首頁；來源健康與執行紀錄位於登入保護的/system頁。既有登入機制與排程不變。
